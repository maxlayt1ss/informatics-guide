# Источники и полезные материалы

1. **Учебник «Информатика. 10–11 классы» (К. Ю. Поляков, Е. А. Еремин)**  
   * **Ссылка:** [https://kpolyakov.spb.ru](https://kpolyakov.spb.ru)  
   * **Зачем использовал:** Использовался для проверки строгих определений позиционных систем счисления, алфавита и правил перевода целых чисел.

2. **Справочник MDN Web Docs / Основы компьютерных наук (Статьи по системам счисления на Habr)**  
   * **Ссылка:** [https://habr.com](https://habr.com)  
   * **Зачем использовал:** Использовался для подборки наглядных примеров быстрого перевода через тетрады, которые чаще всего встречаются в программировании на языке Си.
