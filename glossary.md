# Словарь терминов: Системы счисления

1. **Система счисления (СС)** — это способ записи чисел с помощью заданного набора специальных знаков (цифр) и правил выполнения операций над ними.
2. **Позиционная система счисления** — система, в которой количественное значение каждой цифры зависит от её позиции (разряда) в записи числа. Примером служит привычная нам десятичная система.
3. **Непозиционная система счисления** — система, в которой значение цифры не зависит от её места в числе. Классическим примером является римская система счисления.
4. **Основание системы счисления** — количество различных цифр или символов, используемых для изображения чисел в данной позиционной системе. Оно также показывает, во сколько раз вес каждого следующего разряда больше предыдущего.
5. **Алфавит системы счисления** — полный набор цифр и буквенных символов, допустимых для записи чисел в конкретной системе. Например, в шестнадцатеричной системе алфавит состоит из цифр `0–9` и латинских букв `A–F`.
6. **Разряд числа** — позиция цифры в записи числа, отсчитываемая справа налево начиная с нулевого разряда для целой части.
7. **Двоичная система счисления** — позиционная система с основанием 2, использующая только две цифры: `0` и `1`. Является базовой для представления данных в памяти современных компьютеров.
8. **Шестнадцатеричная система счисления** — позиционная система с основанием 16, широко применяемая в программировании для компактной записи двоичных кодов, адресов памяти и цветов.
